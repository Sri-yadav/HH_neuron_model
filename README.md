# Hodgkin–Huxley Neuron Model

## Overview
This project implements a single-neuron Hodgkin–Huxley model to study action potential generation and neuronal excitability through biophysically grounded membrane dynamics.

## Current Implementation
- Classical Hodgkin–Huxley formulation with sodium, potassium, and leak currents  
- Numerical integration of coupled nonlinear ODEs governing membrane voltage and gating variables  
- Time-dependent external current injection  
- Visualization of membrane potential, ionic currents, and gating dynamics  

## Experiments & Analysis
Initial simulations probe neuronal firing behavior under different current injection regimes, with preliminary parameter sweeps of sodium conductance. The model is used as a controlled computational setting to examine how membrane-level mechanisms shape spike generation and excitability.

## Future Directions
Planned extensions include:
- Systematic parameter sweeps of ion-channel conductances to characterize firing regimes  
- Quantitative analysis of excitability measures (e.g., spike counts, firing rates, thresholds)  
- Extension toward more structured neuron models or higher-dimensional parameter spaces
